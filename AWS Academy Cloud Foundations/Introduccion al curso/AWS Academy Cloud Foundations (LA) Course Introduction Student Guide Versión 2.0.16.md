# Introducción al curso AWS Academy Cloud Foundations

## Descripción general del módulo

Este módulo introduce al estudiante en el curso **AWS Academy Cloud Foundations**, proporcionando una visión clara de su propósito, estructura y relación con el proceso de certificación de AWS. Además, familiariza al alumno con los recursos oficiales de documentación de AWS.

## Objetivos del módulo

Al finalizar este módulo, el estudiante será capaz de:

- Reconocer el propósito del curso **AWS Academy Cloud Foundations**.
- Identificar la estructura general del curso y cómo se organiza el contenido.
- Comprender el proceso de **AWS Certification** y su relación con el curso.
- Navegar de manera efectiva por el sitio web de **documentación de AWS**.

## Propósito del curso AWS Academy Cloud Foundations

El curso AWS Academy Cloud Foundations está diseñado para proporcionar una base sólida en conceptos de computación en la nube utilizando Amazon Web Services (AWS). Está orientado a personas que desean iniciarse en la nube y comprender los principios fundamentales antes de profundizar en servicios más avanzados.

## Estructura del curso

El curso se organiza en módulos progresivos que combinan:

- Contenidos teóricos.
- Ejemplos prácticos.
- Actividades de aprendizaje guiadas.

Cada módulo se apoya en objetivos claros que permiten al estudiante medir su progreso y consolidar conocimientos clave.

## Proceso de certificación AWS

Durante el curso se introduce el proceso de **AWS Certification**, explicando:

- Qué son las certificaciones AWS.
- Cómo se estructuran los exámenes.
- De qué manera el curso AWS Academy Cloud Foundations sirve como preparación inicial para certificaciones fundamentales.

## Documentación de AWS

El módulo también enseña a navegar por el sitio web oficial de documentación de AWS, una herramienta esencial para:

- Consultar información actualizada sobre servicios de AWS.
- Resolver dudas técnicas.
- Profundizar en configuraciones, buenas prácticas y ejemplos.

---
## Requisitos previos del curso

Para comenzar, es importante comprender los conocimientos necesarios para aprovechar al máximo este curso.

### Conocimientos generales requeridos

El estudiante debe contar con conocimientos técnicos generales de **Tecnologías de la Información (TI)**. Entre las habilidades básicas de alfabetización informática necesarias se incluyen:

- Comprensión de conceptos básicos de computación.
- Gestión de archivos y carpetas.
- Uso habitual de Internet y sus servicios.

### Conocimientos generales de empresas de TI

También se requiere una comprensión general de cómo las empresas y otras organizaciones utilizan la tecnología de la información para apoyar sus procesos, operaciones y servicios.

### Conocimientos recomendados (no obligatorios)

Para garantizar un mejor aprovechamiento del curso, se recomienda que el estudiante esté familiarizado con:

- Conceptos básicos de **computación en la nube**.
- Conocimientos prácticos sobre **sistemas distribuidos**.
- Conceptos generales de **redes**.
- Conocimientos prácticos sobre **arquitecturas de varios niveles (multicapa)**.

## Resultados de aprendizaje del curso

Después de completar este curso, el estudiante será capaz de:

- Definir la **nube de AWS** y sus características principales.
- Explicar la **filosofía de precios de AWS**.
- Identificar los **componentes de la infraestructura global de AWS**.
- Describir las **medidas de seguridad y cumplimiento** de la nube de AWS, incluido **AWS Identity and Access Management (AWS IAM)**.
- Crear una **Amazon Virtual Private Cloud (Amazon VPC)**.
- Demostrar cuándo utilizar **Amazon Elastic Compute Cloud (EC2)**, **AWS Lambda** y **AWS Elastic Beanstalk**.
- Diferenciar entre los servicios de almacenamiento **Amazon S3**, **Amazon EBS**, **Amazon EFS** y **Amazon S3 Glacier**.
- Demostrar cuándo utilizar los servicios de bases de datos de AWS, incluidos **Amazon Relational Database Service (RDS)**, **Amazon DynamoDB**, **Amazon Redshift** y **Amazon Aurora**.
- Explicar los **principios arquitectónicos básicos** de la nube de AWS.
- Explorar conceptos clave relacionados con **Elastic Load Balancing (ELB)**, **Amazon CloudWatch** y **Auto Scaling**.

## Módulo 4: Seguridad en la nube de AWS

Este módulo introduce el **enfoque de seguridad de AWS**, explicando cómo AWS y el cliente comparten responsabilidades y qué servicios y prácticas permiten proteger cuentas, identidades y datos en la nube.

### Secciones del módulo

**Sección 1: Modelo de responsabilidad compartida de AWS**  
Presenta el **Modelo de responsabilidad compartida**, que define claramente qué aspectos de la seguridad son responsabilidad de AWS y cuáles corresponden al cliente.

**Sección 2: AWS Identity and Access Management (AWS IAM)**  
Introduce los conceptos clave de **IAM**, incluidos **usuarios**, **grupos**, **políticas** y **roles**, y su papel en el control de acceso a los recursos de AWS.

**Sección 3: Protección de una nueva cuenta de AWS**  
Proporciona una guía para asegurar una nueva cuenta de AWS. Se analiza la importancia de **evitar el uso del usuario raíz** para las actividades diarias y se presentan **mejores prácticas**, como la creación de usuarios de IAM con **autenticación multifactor (MFA)** habilitada.

**Sección 4: Protección de cuentas**  
Destaca otras formas de proteger cuentas de AWS, incluidas las características de seguridad de **AWS Organizations**, como las **políticas de control de servicios (SCP)**.

**Sección 5: Protección de datos en AWS**  
Debate sobre cómo **asegurar datos en AWS**, incluyendo:

- Cifrado de datos en **reposo** y en **tránsito**.
    
- Opciones para proteger los datos almacenados en **Amazon S3**.
    

**Sección 6: Trabajar para la garantía de la conformidad**  
Analiza cómo AWS respalda los esfuerzos de los clientes para implementar soluciones que cumplan con **leyes y regulaciones**. Se revisan las **certificaciones** que mantiene AWS y los servicios de soporte de cumplimiento, como **AWS Config** y **AWS Artifact**.

## Módulo 5: Redes y entrega de contenido

El propósito de este módulo es presentar los **fundamentos de los servicios de entrega de contenido y redes de AWS**, incluyendo **Amazon Virtual Private Cloud (VPC)**, **Amazon Route 53** y **Amazon CloudFront**. Los estudiantes tendrán la oportunidad de etiquetar diagramas de VPC, diseñar y crear su propia VPC, y entender cómo se integran estos servicios en la infraestructura de AWS.

### Secciones del módulo

**Sección 1: Conceptos básicos de redes**  
Analiza conceptos de redes fundamentales que se utilizarán en todo el módulo, incluyendo:

- Red y subred.
    
- Direcciones IPv4 e IPv6.
    
- Notación CIDR (Classless Inter-Domain Routing).
    

**Sección 2: Amazon VPC**  
Proporciona una descripción general de la **terminología clave y características de Amazon VPC**, fundamentales para diseñar y crear VPCs propias.

**Sección 3: VPC Networking**  
Presenta varias opciones importantes de redes en VPC, como:

- Puerta de enlace de internet.
    
- NAT Gateway (puerta de enlace de traducción de direcciones de red).
    
- Puntos de enlace de la VPC.
    
- Uso compartido de VPC e interconexión de VPC.
    
- AWS Site-to-Site VPN, AWS Direct Connect y AWS Transit Gateway.
    

**Sección 4: Seguridad de VPC**  
Explica cómo proteger las VPC mediante **listas de control de acceso (ACL)** y **grupos de seguridad**.

**Sección 5: Amazon Route 53**  
Cubre la **resolución de nombres de dominio (DNS)** y las capacidades de **Amazon Route 53**, incluyendo la conmutación por error de DNS y su relación con la **alta disponibilidad**, que se explorará en detalle en el Módulo 10.

**Sección 6: Amazon CloudFront**  
Analiza las funciones y beneficios de **Amazon CloudFront** como servicio de entrega de contenido (CDN) para mejorar la disponibilidad y velocidad de distribución de contenidos.

# Sección 2: Información de examen de AWS Certification.

## Exámenes de AWS Certification

**AWS Certification** ayuda a los estudiantes a construir **credibilidad y confianza**, validando su experiencia en la nube con una credencial reconocida en el sector. También ayuda a las organizaciones a identificar a profesionales capacitados para guiar iniciativas en la nube utilizando AWS.

### Proceso de certificación

- Debe obtener una **puntuación aprobatoria** en un examen supervisado para obtener la certificación.
    
- Tras aprobar, recibirá sus **credenciales de certificación**.
    
- AWS Certification **no publica una lista completa de servicios o funciones** evaluadas en los exámenes. Sin embargo, las **guías de los exámenes** incluyen una lista actualizada de objetivos y temas cubiertos. Las guías están disponibles en: [Guías de preparación de examen AWS](https://aws.amazon.com/certification/certification-prep/?src=certification-faqs).
    
- La certificación debe **renovarse cada 3 años**. Más información sobre recertificación: [AWS Certification Recertification](https://aws.amazon.com/certification/recertification/).
    

### Nota importante

La información de esta sección se actualizó en marzo de 2019; sin embargo, los exámenes se **actualizan con frecuencia**. Para obtener la información más reciente sobre cualquier examen de AWS Certification, consulte: [Página oficial de AWS Certification](https://aws.amazon.com/certification/).

### Certificación recomendada para este curso

Este curso ayuda a prepararse para el examen de **AWS Cloud Practitioner**.

## Examen de AWS Certified Cloud Practitioner

La certificación **AWS Certified Cloud Practitioner** permite a profesionales con diversos roles tecnológicos y de nube **validar su conocimiento de AWS** y mejorar su **credibilidad profesional**.

### Detalles del examen

- El examen cubre cuatro dominios principales:

    1. **Conceptos de nube**
    2. **Seguridad**
    3. **Tecnología**
    4. **Facturación y precios**

- Es el **único examen fundamental** de AWS y a menudo es el primer examen que los profesionales de TI intentan obtener.

- Aunque el curso **AWS Academy Cloud Foundations** no figura en la guía oficial como preparación recomendada, **cubre muchos de los mismos temas** que los cursos comerciales de AWS (AWS Technical Essentials, AWS Business Essentials, AWS Cloud Practitioner Essentials), por lo que es una buena preparación.

- Los servicios incluidos en el examen cambian a medida que AWS lanza nuevos servicios. Se recomienda poder **describir la funcionalidad general de una amplia gama de servicios de AWS** antes de presentar el examen.

### Recursos oficiales

- Información y registro del examen: [AWS Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner/)
- Guía del examen: [Exam Guide PDF](https://d1.awsstatic.com/training-and-certification/Docs-Cloud-Practitioner/AWS_Certified_Cloud_Practitioner-Exam_Guide_EN_v1.6.pdf)
