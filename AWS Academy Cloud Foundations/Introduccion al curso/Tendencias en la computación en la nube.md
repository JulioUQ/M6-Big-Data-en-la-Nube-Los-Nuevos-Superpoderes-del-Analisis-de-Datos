# Tendencias en la computación en la nube

## Introducción

La computación en la nube cambia constantemente y AWS siempre busca innovar. Amazon Web Services presenta regularmente nuevos servicios y funcionalidades, además de realizar mejoras continuas como la reducción de costos, opciones de facturación más granulares, aumento de cuotas, nuevas regiones y un rendimiento más rápido.

Debido a estos cambios, es fundamental mantenerse al día sobre lo que está ocurriendo en el ecosistema cloud.

Este documento ofrece una visión general de algunas de las últimas tendencias en computación en la nube en AWS, junto con recursos útiles para mantenerse actualizado.

## Últimos avances

### IA generativa en AWS

La inteligencia artificial generativa está transformando la forma en que las organizaciones trabajan. AWS proporciona infraestructura, herramientas y aplicaciones que permiten a los clientes integrar la IA generativa en sus negocios.

A continuación, se presentan algunos de los principales servicios de IA generativa anunciados por AWS:

#### Amazon Bedrock

Amazon Bedrock es un servicio completamente administrado que ofrece una selección de modelos fundacionales (_foundation models_, FM) de alto rendimiento, junto con un amplio conjunto de capacidades necesarias para crear aplicaciones de IA generativa. Este servicio simplifica el desarrollo incorporando principios de seguridad, privacidad y uso responsable de la IA.

#### Amazon Q

Amazon Q es un asistente de trabajo impulsado por IA generativa, diseñado para ser seguro y privado de forma predeterminada. Está integrado en muchos productos de AWS y cuenta con dos ofertas principales:

- **Amazon Q Business**  
    Asistente impulsado por IA generativa que puede responder preguntas, generar resúmenes, crear contenido y completar tareas de forma segura. Puede personalizarse utilizando los datos y la información de los sistemas de la empresa.
    
- **Amazon Q Developer**  
    Asistente de codificación que acelera el desarrollo de software para desarrolladores de todos los niveles. Permite:
    
    - Chatear sobre código
    - Completar código en línea
    - Generar nuevo código
    - Analizar el código en busca de vulnerabilidades de seguridad
    - Realizar optimizaciones, depuraciones y actualizaciones de lenguaje
    
    Además, permite describir una aplicación en lenguaje natural para que Amazon Q Developer genere y proponga el código correspondiente.
