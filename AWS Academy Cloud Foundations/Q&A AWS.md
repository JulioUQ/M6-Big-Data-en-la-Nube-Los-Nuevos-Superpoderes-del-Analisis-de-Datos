¿Qué debo hacer para comenzar?

Si es un estudiante de AWS Academy que reúne los requisitos, es posible que reciba un correo

electrónico en el que se le explica el nuevo beneficio de 12 meses de acceso gratuito a AWS Skill

Builder, las 4 formaciones de AWS Cloud Quest basadas en roles as

ignadas aplicables y cómo

obtener

cupones de AWS Certification, así como dónde debe registrarse. Si no recibe ningún correo

electrónico, puede registrarse accediendo al curso de AWS Academy en Canvas. Seleccione el

elemento del menú de los módulos y desplá

cese hasta el módulo en los Recursos de AWS

T&C.

Seleccione el enlace para activar su oferta de AWS Skill Builder.

¿Qué ocurre después de activar mi oferta?

En un plazo de 3 días hábiles a partir de la confirmación de su interés, recibirá un correo electrónico de

AWS Skill Builder con instrucciones sobre cómo registrarse en su cuenta de AWS Skill Builder. Con su ID

de creador de AWS, inicie sesión en skillbuil

der.aws, donde podrá comenzar las formaciones asignadas.

Asegúrese de que la dirección de correo electrónico utilizada para su ID de Builder sea la misma que

utilizó para registrar su interés en la suscripción gratuita de AWS Skill Builder.

¿Qué se ofrece a través de este programa?

Como estudiante de AWS Academy, obtendrá 12 meses de acceso gratuito a la versión de suscripción

de AWS Skill Builder que incluye no solo cientos de cursos digitales, sino también laboratorios y

experiencias de aprendizaje inmersivas para desarrollar habil

idades prácticas de AWS, y acceso

completo a los materiales de preparación para los exámenes de AWS Certification, incluidas las

experiencias prácticas.

¿Cómo ayudará esto a mis perspectivas profesionales?

Con la IA y las tecnologías en la nube que están remodelando el mercado laboral, los empleadores

buscan activamente candidatos con estas habilidades. Este programa le brinda acceso a toda la gama

de contenido de formación autoguiada desarrollado por expert

os de AWS en IA, computación en la

nube, machine learning, datos, seguridad y otras habilidades con mayor demanda que las empresas

necesitan ahora.

¿Qué contenido de formación específico tengo disponible en Skill

Builder?

Además de obtener acceso total al catálogo completo de formación disponible en un plan de suscripción

de Skill Builder, se le asignarán automáticamente cuatro formaciones de AWS Cloud Quest basadas en

roles y cuatro exámenes de práctica oficiales.

¿Cómo puedo obtener un vale de examen de certificación gratuito?

Dentro de los 3 días hábiles siguientes a la finalización de uno de los exámenes de práctica oficiales

asignados, recibirá un vale para realizar un examen de AWS Certification para el examen del nivel

correspondiente (Foundational o Associate) sin costo. L

os estudiantes son elegibles para recibir un

vale de examen de certificación por cada examen de práctica basado en roles que completen (máximo

4 cupones por estudiante). Las certificaciones de AWS son credenciales reconocidas en el sector que

validan sus h

abilidades técnicas ante los empleadores.

¿Cómo accedo a las formaciones asignadas y seleccionadas?

Tras iniciar sesión en AWS Skill Builder, verá las formaciones asignadas en la pestaña

“

”

(Cursos)

de la sección

“

”

(Su actividad de

formación

reciente) de su panel.

¿Qué sucede si ya tengo una cuenta de AWS Skill Builder?

Si tiene una cuenta de ID de creador de AWS que usa para acceder a AWS Skill Builder, pero no tiene

una suscripción a Skill Builder, solicitará acceso a través del curso de AWS Academy. Si utiliza cualquier

otro método de autenticación para acceder a AWS S

kill Builder o tiene una suscripción, comuníquese

con el servicio de asistencia en

skillbuilder.aws/support

.

¿Qué sucede cuando caduca mi acceso gratuito de 12 meses?

Cuando su periodo de acceso gratuito se acerque a su fin, recibirá información sobre el acceso

continuo

al contenido de la suscripción de AWS Skill Builder a través de una suscripción individual

mensual o anual de Skill Builder, o bien tendrá la opción de dejar que caduque su suscripción

y

aprovechar el contenido disponible a través de la versión gratuita de Skill Builder.

¿Esta oferta está disponible para todos los estudiantes de AWS

Academy?

La oferta está disponible para todos los estudiantes actuales de AWS Academy. Si actualmente

no

es

educador ni estudiante de AWS Academy, visite el sitio web de AWS Academy

(

https://aws.amazon.com/training/awsacademy/

) para obtener información sobre cómo inscribirse.

¿Cómo se usa mi información personal?

Su información personal (nombre y correo electrónico) se compartirá con AWS Skill Builder para aplicar

la promoción de 12 meses gratuitos a su cuenta de Skill Builder. AWS maneja su información personal

de acuerdo con el Aviso de privacidad de AWS (

https://aws.amazon.com/privacy/

).
